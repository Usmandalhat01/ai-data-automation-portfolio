# Contributing

Thank you for taking an interest in this portfolio.

The projects in this repository are practical demonstrations of data, automation, cloud security, and software engineering work. Suggestions and improvements are welcome.

## Local setup

1. Fork or clone the repository.
2. Create a virtual environment.
3. Install the shared dependencies with `pip install -r requirements.txt`.
4. Open the folder for the project you want to run and follow its README.

## Making changes

- Keep changes focused on one project or improvement.
- Use clear commit messages.
- Do not include real payroll, customer, credential, or security data.
- Add or update tests when changing validation or matching logic.
- Update the relevant README when behaviour or setup changes.

## Pull requests

Describe the problem, the change made, and how you tested it. Screenshots are helpful for dashboard changes.
