# Design previews

These files are presentation mockups that show how the projects can look when deployed. They are clearly labelled as previews and are not presented as live production screenshots.

## Included previews

- Operations dashboard
- Payroll validation report
- AWS IAM audit dashboard
- Cybersecurity log analysis dashboard
- Customer support assistant
- API documentation preview
- ETL pipeline overview

The mockups are built as SVG files so they stay sharp on GitHub and can be embedded directly in project READMEs.
